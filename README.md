# Study With Me

A modern study companion application built with Next.js to help students organize study sessions, track progress, and stay productive during exam preparation.

---

## Features

- Study session management
- Focus and productivity tracking
- Progress monitoring dashboard
- Goal-oriented preparation workflow
- Clean and modern UI
- Fully responsive design
- Fast performance with Next.js

---

## Tech Stack

- Next.js
- JavaScript / TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React

---

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/study-with-me.git
```

### Navigate to the project

```bash
cd study-with-me
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```
